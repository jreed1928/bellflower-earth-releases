# Bellflower Earth™ — desktop builds (prototype)

Download page: https://bellflowerlabs.pages.dev/earth/

- **Windows (x64) installer, unsigned.** Windows SmartScreen will probably warn about an unknown publisher. Verify the SHA-256 below before running.

SHA-256 checksums are in `SHA256SUMS.txt` (attached to the release).
